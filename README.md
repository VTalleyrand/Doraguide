# Dora Guide

Dora is a walking audio guide app landing site built with React and Vite.

## Structure

- `client/` contains the Vite React app.
- `server/` contains the Node API and static file server.
- `dist/` is generated by the production build.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Smart App Banner

Safari shows an Open/Get banner on iOS when the site includes the
`apple-itunes-app` meta tag. The banner uses App Store ID `6746723814` and
passes each page's canonical URL as the `app-argument`.
