# Dora Guide

Dora is a walking audio guide app landing site built with React and Vite.

## Structure

- `client/` contains the Vite React app.
- `server/` contains the Node API and static file server.
- `dist/` is generated by the production build.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Smart App Banner

The iOS Smart App Banner code is currently commented out. To re-enable it,
restore the commented Smart App Banner imports and calls in:

- `client/src/appBanner.js`
- `client/src/main.jsx`
- `client/vite.config.js`
- `scripts/prerender.mjs`

It was previously enabled for builds with:

```bash
VITE_SHOW_APP_BANNER=true npm run build
```

The banner uses App Store ID `6746723814` and passes each page's canonical URL
as the `app-argument`.
